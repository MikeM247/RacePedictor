# Asset sources

The road photograph and ORBIT artwork are unchanged copies of this repository's production assets. The DejaVu font files retain the accompanying license.

`comrades-logo.png` is the gold circular Comrades Marathon runner emblem, downloaded unchanged on 30 October 2026 from the [Comrades logo asset in a runner's public site](https://github.com/JpLouw/JpLouw.github.io/blob/adeaa3622671106ce6787c2dd37f909b123b4f52/assets/img/comrades-logo.png). The mark identifies the Comrades milestone in these private design concepts; it is not an application logo or an endorsement. The runner's page labels the image as its Comrades logo. A fresh official-site asset could not be retrieved with the available network access.

Option 07 uses two original, generated concept marks requested by the user on 30 October 2026. They replace the previous temporary HTML distance badges. They are not verified official event logos and make no claim of endorsement.

- `oldies-durban-north-logo.png`: custom Oldies 10 km / Durban North mark, generated from the user-provided race identity. Original generated file: `/workspace/generated_images/exec-4900beb9-7f65-435e-bdf2-ea9a2cf516d3.png`.
- `best-of-the-best-2027-logo.png`: custom Best of the Best Marathon / 2027 mark. Original generated file: `/workspace/generated_images/exec-d3a64a4f-4156-40ee-aae8-8bf54c8b0564.png`.

The user specified Best of the Best Marathon 2027 with a target under 4 hours 20 minutes. This is applied only to the option 07 design preview. The existing sample date, 7 March 2027, could not be independently verified; it is preserved as a provisional design value, not a confirmed event date. The approved training plan and database are not modified.
