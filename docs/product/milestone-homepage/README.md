# Milestone-first homepage requirements package

31 October 2026 · Ready for architecture planning.

Start with [the BRD and full requirements](BRD.md). It specifies option 09’s UI, flows, data authority, Settings milestone/image management and release acceptance criteria. The [initial image assets](assets/README.md) are included locally in this package.

The [milestone completion product plan](MILESTONE_COMPLETION_PRODUCT_PLAN.md) extends this package with result reconciliation, race-result recognition and confirmation, manual alignment, phased delivery and architect handoff requirements (1 November 2026). Phases 1–3 have been implemented against synthetic records; see [the Phase 3 verification report](../../progress/milestone-completion-phase3-20261104.md).

The product owner selected the visual direction. Automatic recognition has its own `RACEPREDICTOR_MILESTONE_RECOGNITION_ENABLED` switch; disabling it leaves milestone management, confirmed relationships and saved review decisions intact.
