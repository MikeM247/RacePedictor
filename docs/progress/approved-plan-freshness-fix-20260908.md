# Approved plan freshness correction — 2026-09-08

## Task Summary

Resolved the false stale-plan warning generated by local Today and the daily coaching reminder.

## Approach

Today compared the complete, growing activity history with the fingerprint captured at approval. A new activity performed after approval therefore invalidated an otherwise unchanged plan. Today now compares only the history through the recorded approval timestamp. Proposal validation and published planning context still use the entire history.

Past rest entries were also being selected as missed workouts. They are now excluded from missed-workout detection, and a prescribed rest day resolves to the rest state.

## Code Changes

- Local coaching repository: optional timestamp boundary for history coverage, using parameterized queries and athlete scoping.
- Local coaching service: apply the same boundary to activity summaries and coverage for approved-plan freshness only.
- Today integration tests: new training, new provider, context republishing, historical edits, late historical imports, deletion, rest days, and unchanged approval/prescriptions.
- Product context: document the distinction between proposal freshness and approved-plan freshness.
